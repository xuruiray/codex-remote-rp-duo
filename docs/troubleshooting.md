# 排障与已知限制

[返回首页](../README.md)

## ADB 找不到设备

运行 `adb devices` 检查状态：

- `unauthorized`：在掌机确认 USB 调试授权。
- `offline`：重新连接数据线，确认设备已解锁，再检查 ADB 状态。
- 没有设备：确认数据线支持传输、USB 调试已打开，并检查 USB 端口。
- 多台设备：设置 `ANDROID_SERIAL` 后再安装或运行配对脚本。

## 构建找不到 SDK 或 Java

确认 `python3 --version` 为 3.11+，`javac -version` 使用 JDK 21，SDK 中存在 `platforms/android-36/android.jar` 及 `build-tools/36.0.0/`。SDK 位置不同可使用 `DUO_PLATFORM_JAR` 与 `DUO_BUILD_TOOLS` 指定。

OpenSSL 参数报错时，检查是否实际用了支持所需命令的版本。可按[安装指南](installation.md#环境准备)配置 PATH。

## APK 签名不匹配

出现 `INSTALL_FAILED_UPDATE_INCOMPATIBLE` 时，通常是正在安装的 APK 与已有应用签名不同。

恢复原 `build/local.keystore` 和 `build/signing-password` 后重新构建。不要直接删除签名文件或把卸载作为默认解决方式；卸载会删除掌机本地草稿和配对信息。

## USB 或证书连接失败

先确认 APK 是使用当前 Mac 的配对 CA 构建的。另一套环境的 Release APK 不能自动信任新生成的 CA。

USB 路径可以检查：

```sh
adb reverse --list
```

应存在 `tcp:38457` 到 `tcp:38457` 的正常转发。重新执行 `./USB.command` 可以恢复配对与转发；若脚本提示需要先停止，则等待任务完成后再按提示重启。

不要通过忽略证书错误来掩盖 CA 不匹配。

## Wi-Fi 不能连接

确认 Mac 与掌机在同一局域网，Mac 的 IPv4 未变化，防火墙允许桥接的局域网连接，并确认网络没有开启客户端隔离。

Mac 使用有线网络或其他网卡时，`en0` 可能不是正确地址。等待任务完成后停止服务，再用实际 `DUO_LAN_IP` 重启配对。IP 变化可以更新服务器证书；CA 保留时通常不用重新构建 APK。

## 会话打不开、模型缺失或提问无法继续

- 确认 Mac 已登录 Codex，当前账号可正常使用。
- 确认安装的 APK 与 Mac 端代码符合 Release 的配套说明，不能只更新掌机而继续使用缺少新接口的旧桥接。
- 优先使用桌面应用捆绑的 Codex 组件，或通过 `DUO_CODEX_BIN` 指定已验证组件；不同版本的分页、置顶和提问协议能力可能不同。
- 部分旧会话原工作目录已不存在，当前实现会提示并使用桥接工作目录作为本轮回退目录，发送前应确认目录。
- 已停止、已过期或已切换的提问会拒绝旧答案，应查看当前会话的提问状态。

## 键盘、退出和日志

模型、推理菜单关闭后应自动恢复键盘。若遇到例外，记录是选择还是取消、当时是否有原生输入弹窗，以及完整操作顺序。临时可以点击输入框恢复输入。

双击返回退出适用于主界面；原生输入框或系统选择弹窗可能先处理返回键、关闭键盘或弹窗。

默认桥接日志位于 `.duo/runtime/bridge.log`；设置 `DUO_DATA_DIR` 时位于该目录的 `runtime/bridge.log`。日志可能含工作目录、命令和消息，反馈前只截取必要且已脱敏的部分。不要上传 token、完整错误链接、证书私钥或签名材料。

## 已知限制

以下是当前代码边界，不表示每条都已在所有设备上复现：

- 首次配对依赖 USB 调试；现成 APK 绑定构建时的 CA，尚无通用配对安装包。
- Android 声明最低为 10，但目前完整真机验证以 Retroid Pocket Duo 为主；未覆盖全部设备、系统版本和无障碍场景。
- 不提供公网中继、多人账户隔离或商店分发。
- 当前运行组件禁用 apps、plugins、hooks 及配置中的 MCP servers；桌面的完整工具环境尚未同步。
- 显示协议公开的思考摘要，不提供模型完整内部思考。
- 正文与命令详情有约 24000 字符的截断保护；单文件 diff 最多返回 240000 字符，尚无正文全文续取入口。
- 回复中的链接当前以文本形式展示，尚无外部浏览器打开入口。
- 跨会话阅读位置、消息和命令的展开状态不保留；收起侧栏后没有独立的后台任务汇总入口。
- 历史记录与 DOM 随加载增长，尚无窗口化渲染；未完成长会话、耗电和内存压力验证。
- 网络路径重连已有处理，Mac Codex 子进程退出后仍需人工重启桥接。服务端发送回执不跨桥接重启持久保存，结果未知时应先核对会话，再决定是否重发。
