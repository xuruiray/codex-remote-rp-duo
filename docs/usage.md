# 双屏使用与配置

[返回首页](../README.md)

## 双屏分工

- **上屏**：会话列表、回复、思考摘要、折叠命令、AI 提问及文件 diff。
- **下屏**：输入框、模型与推理强度、发送/回答/停止，以及常驻键盘。
- 左上角按钮可折叠或展开会话栏，折叠状态会保留。
- 方向键上下或摇杆纵向滚动阅读区；变更面板打开且内容可滚动时，手柄优先滚动 diff。
- 在主界面连续两次按返回键退出双屏客户端。

## 会话与任务

「新聊天 / 置顶 / 全部会话」位于上屏左侧。每行会话菜单提供置顶、重命名、归档或恢复，归档入口在侧栏底部。

多个会话可以同时执行；切换会话不会停止原任务。「停止」核对当前会话和任务，只停止当前选择的任务。打开慢会话时仍可切换其他会话或新建聊天，旧加载结果会被丢弃。

输入草稿按会话保存到掌机本地浏览器存储；重新打开会话可以恢复草稿。向上滚到接近历史顶部会自动加载更早记录。跨会话的阅读位置和展开状态目前尚未保存。

「变更」显示当前记录的本轮文件数量。没有变更时点击会显示提示，有文件时展开侧栏并可逐个查看 diff。这里展示 Codex 记录的当前轮次变更，不等同于整个 Git 工作区的所有未提交改动。

## 模型、推理与 AI 提问

模型列表来自 Mac 当前 Codex 账号。模型支持「高」推理强度时默认选择「高」，不支持的强度不会凭空加入菜单。模型选择目前是页面级状态，不会按会话分别保存。

AI 提问支持两条路径：

1. 等待作答的协议请求：选择或填写全部问题后提交，答案回到原请求，Codex 继续执行。
2. 普通提问卡片：选择或填写答案后提交，通过该会话的续聊发送。

上屏可选择答案、提交或暂不回答；自由文本由下屏输入。多题时会切换到下一条尚未回答的问题。保密输入通过下屏原生密码框填写，公开界面显示掩码。已停止或过期的提问不能继续提交。

## 连接与服务

```sh
# 启动并通过 USB 配对，打开客户端
./USB.command

# 只启动 Mac 服务，不重新配对
./USB.command --serve

# 停止 Mac 服务与 USB 转发
./USB.command --stop
```

服务通过 macOS launchctl 启动。退出掌机 App 不等同于停止 Mac 上的任务或关闭桥接；需要关闭服务时使用 `--stop`。

| 配置 | 作用 |
| --- | --- |
| `ANDROID_HOME` / `ANDROID_SDK_ROOT` | Android SDK 根目录，前者优先。 |
| `DUO_PLATFORM_JAR` | 指定构建使用的 `android.jar`。 |
| `DUO_BUILD_TOOLS` | 指定包含 aapt2、d8、zipalign、apksigner 的目录。 |
| `DUO_DATA_DIR` | 覆盖默认 `.duo/` 数据目录；构建与运行应一致。 |
| `DUO_CODEX_BIN` | 指定 Mac Codex 可执行文件。 |
| `DUO_LAN_IP` | 指定 Mac 的私有局域网 IPv4。 |
| `DUO_USB_ONLY=1` | 仅启动 USB 连接路径。 |
| `ANDROID_SERIAL` | 多设备时指定 ADB 目标；安装前也应设置。 |

数据、签名与连接的边界见 [SECURITY.md](../SECURITY.md)。
